# Trading Strategy Backtester

Учебный движок бэктестинга на C++17. Открывайте раздел **Files** или
**Namespaces → backtest**, чтобы посмотреть документированный API.

## Модель исполнения

- Один инструмент, длинная позиция или деньги; дробное количество единиц.
- Скользящие средние обновляются за O(1) на шаг; весь прогон занимает O(n).
- До заполнения медленного окна портфель остаётся в деньгах.
- Быстрая средняя выше медленной — целевая позиция long, иначе — деньги.
- Сигнал на шаге `i` исполняется по цене шага `i + 1`.
- Комиссия берётся с объёма каждой покупки и продажи.
- Последняя открытая позиция оценивается по последней цене без принудительной продажи.
- Отчёт содержит стоимость портфеля, доходность, максимальную просадку и сделки.

Цены подаются в хронологическом порядке через `std::vector<double>` или CSV
с единственным столбцом `close`. Пустой ряд оставляет начальный капитал без изменений.

## Пример API

```cpp
#include "backtest/backtester.hpp"

const backtest::Config config{1000.0, 0.0, 1, 2};
const auto result = backtest::run({100, 110, 200, 220}, config);
// Покупка на шаге 2 по 200; итоговая стоимость 1100, доходность 10%.
```

## Ограничения

Нет коротких позиций, проскальзывания, дивидендов и ограничений ликвидности.
Цены считаются равноотстоящими наблюдениями. Исторические результаты не
предсказывают будущую доходность. Это учебная модель исполнения, не торговый терминал.

Команды сборки, тестов и бенчмарка находятся в
[README репозитория](https://github.com/Sbivan339/Project_for_quntitative_finance_cpp).
